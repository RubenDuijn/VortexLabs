# Vortex Labs Improvement Roadmap

This roadmap is built to improve conversion and trust without losing the premium visual style.

## Roadmap Maintenance Rule

Use this rule after each implementation task:

1. If the item was implemented, change the line prefix from [ ] to [x] and add a short completion date note.
2. If the item is no longer relevant, remove it from the list.
3. Keep only active, not-yet-done items visible in each phase whenever possible.
4. Review and clean the roadmap once per week.

Example:

- [ ] Rewrite hero headline to be specific about outcome and audience.
- [x] Rewrite hero headline to be specific about outcome and audience. (Done: 2026-05-15)

## Priority Principles

- [ ] Clarity before aesthetics changes
- [ ] Trust signals before advanced redesign
- [ ] Strong CTA system before adding more sections
- [ ] Measure outcomes before scaling effort

## Market Positioning Rule

Use this positioning order consistently across website copy, localized pages, and docs:

1. Switzerland first (Swiss-based, Swiss quality).
2. Core active markets next (DACH, Spain, Netherlands).
3. Broader coverage last (EU).

Preferred short trust line format:

- Swiss-based. Trusted in Switzerland, DACH, Spain, and the Netherlands, serving clients across the EU.

Localization note:

- Keep the same market order in every language: Switzerland -> DACH -> Spain -> Netherlands -> EU.
